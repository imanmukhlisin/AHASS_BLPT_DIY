# AHASS_BLPT_DIY

## About

AHASS_BLPT_DIY adalah proyek PHP untuk membangun sistem manajemen bengkel otomotif (AHASS) dengan fitur DIY (Do It Yourself) yang memudahkan pengguna untuk mengelola inventori suku cadang, layanan perbaikan, dan administrasi bengkel secara digital.

### Fitur Utama
- Manajemen inventori suku cadang
- Pencatatan layanan perbaikan
- Administrasi bengkel
- Antarmuka yang user-friendly

### Teknologi
- **Bahasa Pemrograman**: PHP 100%
- Platform berbasis web untuk kemudahan akses

### Cara Menggunakan
1. Clone repository ini
2. Setup database sesuai konfigurasi
3. Jalankan aplikasi di server lokal atau web hosting
4. Akses melalui browser Anda
